# 分析、合批、重建与验收

## 清单：先查漏，再省调用

按整图 → 九宫格局部 → 边缘 → 遮挡交界巡视并逐项编号。覆盖产品、配件、提手、挂穗、食物、刀具、容器、枝叶、落花、小章、前景、所有文字、反射与光效。不能以“太小”为由遗漏；低清不可辨认元素标为不确定，保留合理位置及视觉作用。

每项记录 ID、名称、类型、原图坐标/大小、视角、颜色/材质、前后关系、遮挡者、承接面、处理路线、部件 ID、生成批次、阴影方式和依据。独立附件应独立编辑；不可拆形体不必碎分。区分物体、部件、生成张数和最终图层数。阴影、文字、背景都计入清单。修正识别结果需同步清单、资产及 scene，不删除失败对象来让检查通过。

## 合批规则

1. 以需生成元素为节点，以实际相交、前后遮挡关系为冲突边。月饼与盘、盘与托盘等有交叠者不能同张生成后硬拆。判断物理边界和被遮挡区域；外接矩形相交不等于像素相交。
2. 包装、刀、月饼确实无像素交叠时可同批生成，原图中彼此距离和位置保持不变，其他区域留空，不串影。不重新排列成素材表；不能把相交物件移开来凑同批。两个月饼如接触/交叠须分批。
3. 用冲突图着色先复用兼容批次，再开新批，同时考虑共同安全底色、原位分辨率、漏件风险。贪心不宣称数学最少。稀细饰物可独立一批，但仍保留原画布；不能省调用而漏元素或放大重排。
4. 完整背景单独生成；容器需去掉上层物体及旧影，补全内底和边沿。未见部分按物理连续性重建，不声称恢复隐藏像素。
5. 每个需生成元素恰好分配一次。一个元素可拆多个部件（如灯笼身和穗），每个部件须有唯一资产及图层 ID。生成后核对数量、孔洞和附件，缺件补生成，不能拿额外物体冒名替代。

## 安全底色

先尝试真实透明，验通道后再决定转换。需要技术底时：

- 检查整批所有前景颜色，包括暗紫、蓝紫、反光、叶片和细线。允许在原图做颜色分析/取样，禁止据此提取原图主体。
- 紫/洋红冲突 → 优先绿色；绿也冲突 → 经检查的青/蓝/黄/红，或分批/原生透明。不是固定紫绿二选一。
- 记录前景代表色 `samples.json`。`asset_ops.py choose` 只是保守辅助；高光、渐变及生成色漂移须复查。
- 提示词指定平整无纹理的十六进制底色，不要地面/影/渐变/背景染色；算法 `--key` 与实际颜色一致。生成底色常不等于精确 RGB，需从边界估计。
- 不安全就换方案；不得删掉主体同色部分，再靠侵蚀或羽化伪装修边。玻璃/彩色反射等不满足色差模型的资产优先原生透明并目视验证。

## 拆件与回填

记录生成图实际尺寸；归一到目标全画布后分件。优先用互不相交且有透明分隔的矩形区域，保留全部 alpha 岛；每件导出仍为原画布和原坐标，不紧裁。全画布边界允许原有出画物件，内部切分线不能切断穗丝。区域无法用矩形分离时调整分批或使用不改轮廓的资产标签，不能硬裁邻物。连通域只辅助定位，不按最大 N 个丢小件。

生成图原画幅须与参考相符；工具仅返回像素取整差时整画布一次归一，真正改画幅/裁切不能拉伸解决。物件原位比对通过即保持不动；必要时仅基于可靠特征做均匀缩放+旋转+平移，记录证据和矩阵，使用预乘 alpha 插值。拒绝单独 X/Y 缩放、剪切、透视硬拟合；真实透视形变需重生成。先排除远处 alpha 噪声撑大 bounds，低纹理匹配不足不强行配准。

颜色/柔焦依据原图可见内部做每部件智能校准，保留 raw 资产。稀疏曲线和全局去色的已知故障见 [v3-lessons.md](v3-lessons.md)。先验证最终颜色及边缘再全量装配；任一阶段失败只修相关组件。

## 双层阴影

落在承接面上的物体组，由下到上：扩散投影、接触实影、主体；反射另层。保留自身明暗，素材不得烘焙外部影。

- 接触实影跟随与承接面相交的真实底缘：近、窄、深、小模糊。立体物沿每列实际下缘，不把整个主体压成水平黑条。有脚、孔、悬挑时仅保留真实支撑点，不把所有下轮廓都涂黑。薄物件可用自身轮廓轻移。
- 扩散影依据原图光源方向，宽、浅、较模糊；离面越高通常越软越远。复杂形体结合接触点和透视投影，不能套椭圆或固定偏移。
- 案例光从左上、影向右下，其他图重新判断；所有参数随画布和物体尺寸调整。
- 月饼影落盘内、盘影落托盘、流苏影按高度落包装/托盘/台面。需要裁切时保留完整影，在 PS 用可编辑蒙版/分段层处理；这不等于从原图抠主体。跨多个承接面可额外分层并说明，不能为凑两层牺牲真实关系。
- Multiply、独立不透明度、智能高斯模糊；脚本只生成初始轮廓，开关影层目视修正。
- 悬挂灯笼用自身明暗及近/远发光，无承接面不画落地实影。图章和虚化前景不机械加双影。

## 验收

结构：每个部件 ID 唯一对应图层，文字原生，物件嵌入智能对象，需要的双影完整，引用存在，比例正确，参考隐藏，旧文件未变。

视觉：整图与原图并排/叠加看位置、大小、比例、透视、色调和细节；100%～200% 浅/深/实际背景检查彩边、锯齿、断穗、孔洞及不透明区域暖色污染。虚焦边还需查亮度/饱和度，防粉边变黄绿晕；移走主体查旧影/缺口，开关双影查贴地与方向，核对文案。

原生：保存重开，编辑文字恢复，移动整组并确认两影同行后恢复；重开导出与 PSD 缓存图对比。导出纯背景、空容器、无影视图目视。实际完成的检查才记 PASS。

交付：新版本 PSD、预览、图层与生成说明；按需透明 PNG。说明实际生成/文字/矢量/程序阴影方法及具体差异，不说成无损恢复。
