# V3 / V3.1：问题、修复与检查关口

用于原位重建、细边/虚焦残色和局部修正。案例数值不是通用预设。

## V3：形变、色偏及细边

| 失败步骤 | 根因 | 修复与验证 |
|---|---|---|
| 生成提示词 | “素材表”允许重新排布；容器变成横版单品并放大 | 原图为编辑目标，完整原画幅原位编辑，生成后先看位置/比例/透视。 |
| 回填 | 外接框独立缩放 X/Y，掩盖生成形变 | 禁止 frame 拟合，输入全画布。只用均匀缩放、旋转、平移，记录矩阵依据；透视变了就定向重生成。 |
| 合批 | 两个月饼看似独立，实际像素交叠 | 按真实像素及遮挡建立冲突图，分批；不移动目标来凑同批。 |
| 定位 | 淡远处底色碎点把 bounds 撑满画布 | 配准前查 alpha 支撑范围，只清已确认技术噪声；保护小花细穗，不取最大连通域替代物件。 |
| 去底修边 | 侵蚀高 alpha 核心，丢掉细窄深色提手边，最近颜色变高光而产生白齿 | RGB 参考核心不侵蚀。`refine-mixed` 仅对已诊断混色边缘使用，保留 alpha，默认不运行；不适合通用玻璃/虚焦修复。 |
| 色彩校准 | 三点曲线在端点截断后发生样条弯曲，意外压暗中间调 | `rgbOffsets` 使用 9 点：x=0,32,64,96,128,160,192,224,255，y=clip(x+偏移)，并用灰阶条做原生回归。 |
| 多材质校色 | 灯笼身和穗误差不同，整体校准顾此失彼 | 按部件/材料比较原图可见内部稳健统计，排除旧影、底色、混合边缘及异常高光。景深用智能模糊。 |

SIFT/RANSAC 只辅助定位，需足够且分布合理的内点；低纹理盘子匹配不足时不强行拟合。相似矩阵合法、外接框一致不等于透视正确。变换采用预乘 alpha 插值再还原 RGB，防暗边。

## V3.1：残留粉红与暖色污染

旧检测 `min(R,B)-G` 可找到明显洋红，但洋红混入金色会变成粉红/红棕而漏检。污染也会存在于 alpha=255 的内部，校色和模糊后可能显露/扩散。因此在最终滤镜后检查透明边和不透明部分；低“紫色像素数”不能证明干净。

先保护真实材质：木纹红棕、兔耳粉红、金属暖反光不能全局清除。只修诊断确认的组件和色域。V3.1 修复 11 个装饰部件，其余 8 个部件 RGBA 不变。

Photoshop Hue/Saturation 陷阱：`Chnl` 整数会静默作用于主通道，令整块金色变青。正确使用 `localRange` 及明确 `BgnR/BgnS/EndS/EndR`；漏范围会报程序错误。脚本已封装，不能改回全局色相。

本例洋红范围 [255,285,315,345]，红范围收窄至 [315,345,10,30]；原先末端 45 度污染正常金色。一般金色装饰洋红 hue +90、红 hue +40，仅是本例局部修复，不适用于所有素材/绿色技术底。

虚焦前景仅转色相出现黄绿亮边，最终同时调整色相/饱和度/明度：洋红 +100/-55/-40，红 +50/-55/-45。必须在实际背景看亮度与饱和度，不能把粉红换成另一种光晕就算通过。

## 修复与验收边界

- 纯改色：最终 PNG alpha 与修前逐像素一致，位置大小不变，保护物件 RGBA 或内容哈希不变。确实改变几何/景深时记录预期变化，不套用旧 alpha 相等要求。
- 100%～200% 看浅底、深底、实际承接面，重点提手内缘、穗丝、细枝、离焦前景；检查白齿、黄绿晕、黑边和真实红色丢失。
- 像素计数仅用于辅助定位，不能要求粉色一律归零，也不能代替目视。
- “保护组件”须前后原生 RGBA 一致；已施加局部色域滤镜的组件内部安全色可能出现原生量化小差异，应单独记录并目视，不能承诺整组件安全色绝对零变化。本次合成色块回归金色最大通道差 2/255，绿/蓝/灰不变；这个值不是任意照片的统一容差。
- 滤镜顺序：景深/亮度对比度 → RGB 校准 → 局部色域去污染；改变顺序需重新检查该组件。
- PNG 从最终 PSD 隔离导出，画布坐标和颜色与 PSD 一致，不能交付滤镜前 raw PNG 冒充最终素材。

## 减少重试与中断恢复

1. 生成前完成清单、冲突、安全底色检查；高风险细穗/虚焦/反光资产先验证，沿用已通过的批次，不额外重复试样。
2. 四道关口：原位几何/完整性 → 真 alpha/细边 → 最终色彩/景深/残色 → 阴影与 PSD。上游失败不进入全量合成。
3. 每个 component_id 持久化源路径/哈希、画布、区域、相似变换、RGB 偏移、色域范围、滤镜顺序、QA 状态；中断从最后通过阶段继续。
4. 纯残色无需重生成。用 `basePsd` + `patch:true` 在副本替换目标，输入未经这些滤镜处理的全画布资产及完整滤镜声明，不重复叠加。改几何同时更新关联阴影，改颜色保持阴影。
5. 同种错误再次出现先检查具体失败条件，不反复提交同样请求。无法可靠还原时报告偏差，不宣称像素级恢复。

## 已确认案例结果

月满人间 V3.1：1152×2048，7 根组、59 内容层，53 嵌入智能对象和 6 原生文字；19 物件部件、30 独立阴影。19 个 alpha 与 V3 完全一致，8 个保护部件 RGBA 不变；重开合成 RGB 均差为 0，文字修改恢复、流苏及双影移动恢复通过，旧版哈希不变。

数量、尺寸、参数及 PASS 只属于该案例；未来图片重新分析验收。“尽量一次通过”是流程目标，不承诺隐藏区域、生成细节或商标文字逐像素相同。
