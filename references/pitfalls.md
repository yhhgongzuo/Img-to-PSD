# 已发生问题与防复发

| 现象/原因 | 修复与检查 |
|---|---|
| V1 多边形/GrabCut 抠物，边缘被啃 | 生成完整物件；不复用旧抠图像素/蒙版，不靠羽化掩盖缺失。 |
| PNG/绘制棋盘格被当成透明 | 检查实际 alpha；RGB 棋盘格拒收，不将棋盘格颜色一起删。 |
| 请求透明多次仍返回 RGB | 换安全纯色技术底，记录真实方法，不无限重复。 |
| 紫物紫底误删 | 整批颜色预审；安全绿底/其他色/分批/原生透明。 |
| 换绿底但算法仍洋红色差 | 底色和算法参数一致；紫物绿底、绿物紫底分别测试。 |
| 底色不是精确 #FF00FF | 估计实际背景色场，不只按 RGB 相等删像素。 |
| 素材重新排布/外接框拟合导致漂移形变 | 原画布原位生成，全画布分件；禁止 frame 拉伸，只允许有证据的相似配准。 |
| 最大连通域丢细穗小花 | 清单核对，留白区域保留全部 alpha 岛，不静默舍弃。 |
| 同表物件相交，重新落入抠图 | 生成前遮挡冲突分批；返回仍相交就修正/拆批。 |
| 原盘/托盘拼回产生旧影接缝 | 生成完整空容器及背景，隐藏上层检查。 |
| 素材烘焙影再叠新影 | 提示词去外部影，单件及背景检查，只留自身明暗。 |
| 通用椭圆影失真 | 按轮廓、接触点、高度、光源和承接面做两层影。 |
| 完整形体压到基线形成黑条/悬浮 | 实影沿真实下缘/支撑点，软影独立。 |
| 悬挂灯笼落地实影 | 按空间关系用近远发光，无承接面无接触影。 |
| 生成物过亮像贴纸 | 场景中校色，用可编辑调整/智能滤镜。 |
| 只数层，没查视觉 | 结构验收加 PS 重开编辑移动和去物视图目视。 |
| JSX/校验中文乱码 | UTF-8 读取 JSX；Python `-X utf8`；结构化传路径。 |
| 覆盖旧版或未实际交付 | 新版本默认拒覆盖，副本哈希校对。 |
| 原图可见底层掩盖漏层 | 参考组隐藏，关闭其他层不应出现整张原图。 |
| 夸大模型版本和编辑性 | 只报告已知版本，文字/形状/智能对象按实际类型说明。 |
| 验证器把原生形状误报为位图、把顺序反着判 | psd-tools 原生形状类型可能为 shape/solidcolor；它从底到顶遍历，与 PS DOM 相反。用真实 PSD 回归验证。 |
| 复制 PSD 后智能滤镜层暂报整张画布 bounds，误判整组移动失败 | 在临时重开文档内做整数 1px 往返使 bounds 更新，再验 X/Y 移动及恢复；必须同时比对重开合成与保护组件像素，不能放宽位置误差掩盖真实漂移。 |
| PNG 全透明区域 RGB 与 raw 不同，被误报变色 | PS 可能改写 alpha=0 下不可见 RGB；raw→原生导出比较可见 RGBA 与完整 alpha，保护组件的原生导出前后仍作全 RGBA 检查。 |

## 当前确认标准

V2 的形变与色偏后来被用户否决，不能把其素材表布局作为成功模板。当前以 V3 原位几何修正及 V3.1 去污染结果为案例依据，详见 [v3-lessons.md](v3-lessons.md)。

重点新故障：原位提示词缺失、XY 拉伸、两个相交月饼错误合批、远处 matte 噪声撑大 bounds、侵蚀颜色参考造成白齿、三点曲线中间调弯曲、opaque 暖色污染漏检、Hue/Saturation 主通道误用、仅换色相产生黄绿晕。

按 v3-lessons 的对应关口拦截，使用脚本回归验证实现。原生结构和重开一致只是必要条件，未来图片仍需目视检验，不预填过去案例的 PASS。
