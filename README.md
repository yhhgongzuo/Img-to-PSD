## 🎯 这个 Skill 能帮你解决什么

- 把一张海报图 / 电商图 / 宣传图，自动逆向重建成**分层完整、可自由编辑**的 PSD 源文件
- 文字双击即可改、产品道具可单独移动替换、背景可单独取用
- 全程只需 3 步，不需要你手动一点点抠图

**适合谁**：电商设计师、AI 设计爱好者，以及任何想把 AI 出图变成「可编辑工程文件」的人。

## 🧠 先搞懂一件事：这不是「拆图」，是「重建 PSD」

很多人以为这个 Skill 就是「自动抠图」，其实不是。抠图只是把画面里的元素剪下来；而这个 Skill 的核心理念是 **重建**——像设计师从零做稿一样，把文字还原成文字图层、把图形重绘成可编辑形状、把被主体挡住的背景补全，最终交出一个接近设计师原始工程文件的 PSD。

## 🖥️ 支持平台

| 平台 | 能否直接使用 | 生图模型 | 说明 |
|---|---|---|---|
| GPT Codex（海外） | ✅ 直接导入即可 | 默认 GPT Image 2.5 | 开箱即用，效果最好 |
| 豆包（国内） | ✅ 需手动改模型 | 换成与平台匹配的国内生图模型 | 把文件里的 GPT Image 2.5 全部替换 |
| WorkBody（国内） | ✅ 需手动改模型 | 换成与平台匹配的国内生图模型 | 同上 |

> 💡 **必须切换到「工作模式」**：不管是海外的 Codex，还是国内的豆包、WorkBody，都必须先切换到「工作模式」（可以接管电脑、执行任务的模式）再运行。普通对话模式只能聊天，无法操控电脑和 Photoshop，Skill 不会生效。

## 📦 安装与使用（三步上手）

整个操作非常简单，核心就是：**导入文件 → 自动装好 Skill → 发图下指令**。

### 第一步：切换到工作模式

在你的 AI 工具里切换到「工作模式」，确认它具备操控电脑、执行任务的权限。

### 第二步：导入 Zip 文件，自动安装 Skill

下载安装包：**[image-to-layered-psd.zip](https://github.com/yhhgongzuo/Img-to-PSD/releases/latest/download/image-to-layered-psd.zip)**

把这份安装包直接导入到工作模式的任务窗口中发送，并附上提示词：

```
帮我安装这个skill，安装完后告诉我使用方法！
```

**可观察结果**：AI 回复已理解并建立「PSD 重建」相关能力 / Skill，等待你发图。

### 第三步：上传图片，发送「拆分PSD」

上传任意一张需要拆分的图片，然后直接发一句：**拆分PSD**。

AI 会自动调用刚装好的 Skill，开始分析结构、重建各图层，必要时接管 Photoshop 执行精修，完成后把 PSD 文件交付给你。

## ⚠️ 注意事项 & 常见问题

**图片太大、超过 4K 怎么办？**
Skill 会自动处理：长边超过 4096 像素的图会先等比缩到 4096 以内，且绝不改变原始宽高比；PSD 画布尺寸与处理后的图完全一致。你不用手动改，但要知道：图越大越费额度，别一上来就拿超大图硬跑。

**用豆包 / WorkBody 具体要改哪里？**
把文件里所有「GPT Image 2.5」替换成你所用平台上最强、最匹配的生图模型（背景补全、产品重建、道具重建三处都会调用它）；如果平台能通过 API 接通 GPT Image 2.5，则无需替换。

**拆一次要多久？建议先用什么图练手？**
简单图快、复杂合成图慢且更费额度。建议第一次先用元素少、遮挡少的简单图跑通全流程，确认效果和操作都没问题，再拆复杂图。

**关于 token / 额度消耗**
图层重建属于重度任务，目前相当费 token、吃额度，请谨慎操作。实际消耗会随图片难易程度浮动：元素越多、遮挡越复杂，消耗越高。建议先用简单图片跑通流程，确认效果后再拆复杂图，避免额度白白浪费。
